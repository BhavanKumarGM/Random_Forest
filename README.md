# Random Forest Classification using Scikit-learn

This project demonstrates how to train, evaluate, and use a **Random Forest classifier** on a built-in **scikit-learn dataset**.

---

## 📌 Overview

- Algorithm: Random Forest Classifier
- Dataset: Iris (from `sklearn.datasets`)
- Tasks:
  - Train a Random Forest model
  - Evaluate accuracy
  - Generate confusion matrix
  - Predict on new, unseen data
